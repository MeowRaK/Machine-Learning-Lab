# Lab 10 — Support Vector Machines (SVM) Assignment

This repository contains a completed implementation of **Lab 10: Support Vector Machines (SVM)** using the Iris dataset.

## 📌 Assignment Overview

The notebook covers the full SVM workflow, including:

* Importing and exploring the Iris dataset
* Data visualization using:
  * Pairplots
  * KDE plots
* Data preprocessing
* Train-test split
* Training an SVM classifier using `SVC`
* Model predictions
* Evaluation using:
  * Confusion Matrix
  * Classification Report
* Hyperparameter tuning using `GridSearchCV`
* Comparing model performance before and after tuning
